## User guide (from the AVsitter documentation)

The notecard format and features are the same as AVsitter's, so the AVsitter user guide applies to LuaSitter. Where the guide says "AVpos", LuaSitter also accepts the new name `LSpos` (see [Notecard names](luasitter/migrating-from-avsitter.md#notecard-names)). Each page starts with a note about LuaSitter, and some pages end with a "LuaSitter notes" section.
